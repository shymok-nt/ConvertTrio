# ConvertTrio

ConvertTrio is a web-based file conversion toolkit. This repository is being built from scratch.

## Development

Requirements: Node.js 22 LTS or newer and npm.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

> Initial scaffold only. File conversion functionality will be added in subsequent stages; no conversion capability is claimed yet.
